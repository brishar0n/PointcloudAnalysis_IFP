# Width Metrics Module

**PIC: Sujeeth Gunasekaran**

Calculates pedestrian sidewalk accessibility metrics from classified LiDAR point cloud data and boundary extraction outputs.

Supports both:

- Point-based sidewalk width estimation
- Boundary-based width estimation

Outputs are used for accessibility analysis and visualisation.

## Inputs

### Point-Based Metrics

Input:

```text
classified/{city}_mlp_classified.laz
```

Generated by the classification module.

Required labels:

| Label | Meaning |
|---|---|
| 2 | sidewalk |
| 11 | street |

Optional obstacle labels:

| Label |
|---|
| 0 |
| 5 |
| 8 |
| 13 |
| 15 |

### Boundary-Based Metrics

Inputs generated by Ahmed’s boundary extraction workflow:

```text

```

Supported formats:
- .las
- .laz
- .obj

## How to Run

### Point-Based Metrics

```bash
python3 -m metrics.width_metrics \
--input-metric classified/utrecht_mlp_classified.laz \
--output outputs/utrecht_width_metrics
```

---

### Boundary-Based Metrics

```bash
python3 -m metrics.width_metrics \
--kerb-file outputs/sidewalk_KI.laz \
--hfe-file outputs/sidewalk_HFE.laz \
--output outputs/utrecht_width_metrics
```

## Point-Based Workflow

```text
classified/<city>_mlp_classified.laz
    │
    ▼
Extract sidewalk points (label 2)
    │
    ▼
PCA walking-direction estimation
    Sidewalk direction estimated using Principal Component Analysis
    │
    ▼
Projection onto along/across axes
    │
    ▼
Fixed-length sidewalk segmentation
    │
    ▼
Per-segment metrics:
    - overall width
    - usable width
    - obstacle count
    - slope
    │
    ▼
Robust percentile filtering
    Removes unrealistic widths caused by classifier spillover
    or large open urban areas
    │
    ▼
CSV + JSON + segmented LAZ outputs
```

---

## Boundary-Based Workflow

```text
Boundary extraction outputs
(KI + HFE)
    │
    ▼
Nearest-neighbour distance estimation
    │
    ▼
Outlier filtering
    Removes unrealistic boundary mismatches
    │
    ▼
Boundary width summary statistics
```

## Notes

- Widths above 15m are filtered because they are usually caused by classifier spillover or large open urban areas.
- Boundary-based estimation generally produced more stable width estimates than point-based estimation.
- Experimental SOR filtering was explored separately but was not included in the final integrated workflow due to limited improvement across datasets.
- Point-based width estimation remains the primary integrated workflow.
